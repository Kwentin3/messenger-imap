# Releases

This directory is a placeholder for release policy notes.

Do not commit APK, AAB, signing keys, keystores, or generated build outputs to the repository.

If Android binaries need to be shared, use GitHub Releases or a controlled distribution channel. Each release should include:

- version;
- channel;
- date;
- APK filename;
- SHA-256 checksum;
- source commit;
- known limitations;
- license/compliance notes.
